# 01 Vision

| Repwise · Vision |  |  |  |  |
| Why this app exists, what 'King of Google Play' means, who it serves. |  |  |  |  |
| ← Back to Start Here |  |  |  |  |
| Vision | Everyone who walks into a gym knows exactly what to lift and what to eat today — without a coach, a spreadsheet or a nutritionist. |  |  |  |
| Mission | Replace the personal trainer + nutritionist + logbook with one beautifully simple, lightning-fast app at a fraction of the price. |  |  |  |
| Positioning statement | For gym-goers who want results but don't know what to lift or eat, Repwise is the AI planner that writes a fresh workout and a fresh menu for you every day and adapts them to your progress. Unlike Leap's Gym Workout (ads, workout-only, no meals) or Fitbod (workout-only, $80/yr) or meal apps (food-only), Repwise joins training and nutrition in one premium, ad-free experience. |  |  |  |
| Tagline | Train smart. Eat right. Every day. |  |  |  |
| North Star metric | Weekly active planners: users who complete ≥ 2 workouts AND tick ≥ 7 planned meals in a week |  |  |  |
| Why we will win | The reference app (Leap 'Gym Workout Planner & Gym Log', 14M Android installs, ~$30–70k/month est.) is ad-heavy, workout-only and full of billing complaints. Category leaders charge $60–80/yr for workouts OR food. We ship both, AI-personalised, with Uber-level polish and no ads. |  |  |  |

| Product principles (use these to settle every debate) |  |  |  |  |
| Principle | What it means in practice |  |  |  |
| Context first | Never show an empty app: the quiz builds the plan before Home appears. |  |  |  |
| Today, not menus | Home = what to do and eat today. Everything else is one tap away. |  |  |  |
| One-tap logging | Weights pre-filled from last time; tick a set or a meal in one tap. |  |  |  |
| Fresh but sensible | Variety every day, inside proven training and nutrition rules. |  |  |  |
| Speed is a feature | Every tap < 100 ms; optimistic UI; media cached; no spinners after first launch. |  |  |  |
